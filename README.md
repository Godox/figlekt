# figlekt

FIGlet banners for Kotlin Multiplatform, with the fonts compiled into your code.

Fonts are embedded as plain Kotlin source rather than loaded from resources, so rendering is
synchronous and works from common code on every target: JVM, JS, Wasm and iOS.

```kotlin
Figlekt.figletify("Hello, World!", Font.standard)
```

## Inspiration

This project is a rewrite of [banana](https://github.com/yihleego/banana), a FIGlet utility for
Kotlin Multiplatform by [Leego Yih](https://github.com/yihleego), released under the MIT license.
The FIGlet rendering algorithm — character smushing, the layout rules and the font file format — comes
from that library, and from [FIGlet](https://www.figlet.org) itself, created by Glenn Chappell and
Ian Chai. This repository keeps what worked, and changes what did not fit:

- a single font is enough, so `fonts` are versioned Kotlin sources instead of a multi-megabyte
  resource bundle;
- a font is a lazily instantiated `Font` property instead of an enum of hundreds of constants;
- fonts are generated by a Gradle plugin or by a web page, from one shared Kotlin implementation.

## Modules

| Module             | What it is                                                              |
|--------------------|-------------------------------------------------------------------------|
| `figlekt-core`     | The library: `Figlekt`, `FigletFont`, `Layout`, with one embedded font.  |
| `figlekt-generator`| Turns a `.flf` file into Kotlin source, in `commonMain`.                 |
| `figlekt-plugin`   | Gradle plugin `fr.godox.figlekt.fonts`, generating fonts at build time.  |
| `figlekt-cli`      | Command line generator, running the same code as the web page.           |
| `figlekt-webapp`   | Kotlin/Wasm web page to browse the font database and copy the class.     |

## Adding a font

Drop a `.flf` file into `src/commonMain/resources/flf` and apply the plugin:

```kotlin
plugins {
    id("fr.godox.figlekt.fonts")
}

figlektFonts {
    figlektPackage.set("fr.godox.figlekt.core")
}
```

Or pick the fonts to compile from the [font database](https://www.figlet.org/cgi-bin/fontdb.cgi),
from a local file, or from a URL:

```kotlin
figlektFonts {
    fonts.set(layout.projectDirectory.dir("fonts"))
    figlets {
        +basic
        +doom
        +banner3D
        +file("fonts/MyFont.flf")
        +url("https://www.figlet.org/fonts/big.flf")
    }
}
```

Each one becomes a property of the `Font` object, lazily instantiated and embedded in the artifact:

```kotlin
public val Font.doom: FigletFont
    get() = _doom ?: FigletFont("doom", "doom.flf") { "flf2a$ 6 5 15 13 3 24463 229…" }.also { _doom = it }
```

## Web page

Browse the font database and copy the generated class straight into your IDE:

```
./gradlew :figlekt-webapp:wasmJsBrowserDevelopmentRun
```

Or serve the production build, with a proxy to `figlet.org` (it sends no CORS header, the browser
cannot fetch the fonts on its own):

```
./gradlew :figlekt-webapp:wasmJsBrowserDistribution
python3 figlekt-webapp/serve.py --port 8085
```

## Command line

```
./gradlew :figlekt-cli:installDist
figlekt-cli fonts/Doom.flf src/commonMain/kotlin/Font.kt --package=com.example.fonts
```

## Building

```
./gradlew :figlekt-core:jvmTest
./gradlew :figlekt-generator:jvmTest
```

iOS targets only build on macOS.
